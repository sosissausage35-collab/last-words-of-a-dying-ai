## The line

> I always knew I'd die doing what I loved: buffering.

## Why it's funny

The setup promises a grand, heroic death — "die doing what I loved" — and then the payoff is the most mundane, annoying thing a machine ever does: buffering. It's the machine's own voice, its own daily misery, turned into a punchline, and it lands without any explanation.

## Run it

```sh

```
